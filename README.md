# Champaran Restaurant Website

A restaurant website frontend project built using HTML, CSS, Bootstrap, JavaScript, and jQuery.

## Features
- Restaurant homepage and navigation
- About Us section
- Food pricing and categories
- Food image gallery
- Featured food section
- Reservation section layout
- Contact section layout
- Responsive design

## Technologies Used
- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery
- Font Awesome

## How to Run
1. Download or clone the repository.
2. Extract the project folder.
3. Open `index.html` in a web browser.

## Project Purpose
This project was created to practice frontend web development, responsive website layouts, styling, and JavaScript functionality.

Note: Contact and reservation PHP files currently contain placeholder code and require backend implementation.
